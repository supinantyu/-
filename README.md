# クーの読書記録タイマー PWA版 v7

v7では、読書ステータスと読後タグを追加しました。

## v7追加機能

- 本ごとの読書ステータスを追加
  - 読了
  - 投了
- 本の詳細画面下部に緑色の「読了」ボタン、オレンジ色の「投了」ボタンを追加
- 読了ボタンを押すと、本棚カードが緑系に色分け
- 投了ボタンを押すと、本棚カードがオレンジ系に色分け
- 同じステータスボタンをもう一度押すと解除
- 読後タグを追加
  - 怖い
  - 泣ける
  - 爽快
  - 難しい
  - どんでん返し
  - 文章が好き
  - キャラが好き
  - 世界観が好き
  - 考察したい
  - 余韻がある
  - 読みやすい
  - 重い
- 本棚カードと詳細画面にタグ表示
- 既存のv6データをv7形式に自動補正

## 注意

AI総合感想機能はv6の仕様を引き継いでいます。  
`app.js` の `AI_SUMMARY_ENDPOINT` が空の場合は、Cloudflare WorkersのURLを設定してください。

Service Workerのキャッシュ名は `kuu-reading-timer-v7` です。  
反映直後に古い画面が出る場合は、Safariで再読み込み、またはホーム画面PWAを削除して追加し直してください。

## v8追加修正：スリープ対応タイマー

- タイマーを `setInterval` の加算式から、開始時刻ベースの計算に変更しました。
- 読書開始時に `timerStartedAt` を保存し、表示時に `Date.now() - timerStartedAt` で経過時間を計算します。
- スマホがスリープ・バックグラウンドになっても、戻ってきた時に正しい経過時間へ補正されます。
- 読書中は Screen Wake Lock API により、対応環境では画面スリープを防止します。
- 読書終了・中止時には Wake Lock を解除します。

注意：
Wake Lock APIは環境によって効かない場合がありますが、開始時刻ベースの計測にしているため、Wake Lockが効かなくても時間計測は補正されます。

## v11追加修正：クーの見解アップデート

AI総合感想機能を「クーの見解」機能に変更しました。

### 変更内容

- 画面表示を「AI総合感想」から「クーの見解」に変更
- ボタン名を「AIで生成」から「クーに見解を聞く」に変更
- 生成中表示を「クーが感想を読んでいます……」に変更
- 本棚カードの表示を「クーの見解：作成済み」に変更
- Cloudflare Workerのプロンプトを、クーの人格・話し方・分析方針を強く反映したものに変更

### 出力方針

クーは本の内容を勝手に要約するのではなく、ご主人様が残した感想ログを読み取り、
ご主人様の読書体験について見解を返します。

出力は次の構成です。

- 【クーの見解】
- 【ご主人様に刺さっていそうな点】
- 【少し引っかかっていそうな点】
- 【クーからひとこと】

### 重要

Cloudflare Workers側も更新が必要です。  
ZIP内の `cloudflare-worker-ai-summary.js` の中身を、Cloudflare Workersの `worker.js` に上書きしてDeployしてください。

PWA側だけ上書きしても、Worker側のプロンプトが古いままだと出力内容は前のAI要約寄りになります。

Service Workerキャッシュ名は `kuu-reading-timer-v11` です。
